# 论文插图 · 交付包

从 20 篇小学语文/科学教研材料中提取图像、净化、**均衡拆分**，产出可直接插入论文的插图。

```

    ├── F03_…_图版1.png / _图版2.png   长教案按课时拆分
    ├── F01_…_图组01.png             图像组：一主图 + 小图（4–9 张）
    └── …
```

## 拆分规则（均衡，非按上限硬切）

| 层 | 规则 | 尺寸 |
|---|---|---|
| **图版** | 每篇 1 张；教案含 2 课时时**按课时拆成 2 张**（教学设计随第一张） | 9.3–31.2 cm，中位 **17.4 cm** |
| **图像组** | 每组 **4–9 张**，各组张数尽量接近（如 20 张 → 7+7+6，17 张 → 9+8，14 张 → 7+7） | 11.4–13.4 cm，中位 **12.3 cm** |
| **图版附图像区** | 若某篇剩余图像**不足 4 张**（成组会造成孤立小图），则并入图版呈现，**不单独切组** | 约 3 cm/张 |

组内版式：`2 图`→左主右小（63/37）；`3 图`→上主图 + 下 2 等分；`4–9 图`→上主图 + 下排均分小图（行数按张数自动推算）。主图取组内**面积最大者**，其余等比缩放至单元格并对齐行高。

规格：图版宽 2309 px、图像组宽 1800 px，均 @300dpi；图版 PDF 文本层可提取。

## 已按要求执行的调整

**① 不再按固定数量硬切**
原按「每 4 张一组」硬切，会把 5 张切成 4+1（后者是孤立的单图）。现改为**均衡分组**：先求最少的组数，使每组落在 4–9 张且各组张数差 ≤1。若剩余不足 4 张，则并入图版呈现，不单独成组。

**② 排除「无真实场景的纯文字介绍图」**
剔除校徽／校训／校风／教风／学风板块等学校品牌图（4 张），以及页眉横幅、二维码尾页、分隔条、图标、花叶色块气泡等，共剔除 138 张。

**③ 弱化举办单位与地址**
图版中不出现主办／承办单位与地址；副标题与环节文本中的校名、区名已去除。

## 给 agent 的读取方式

```python
import json
idx = json.load(open("插图索引.json", encoding="utf-8"))
for a in idx["figures"]:
    print(a["id"], a["kind"], a["title"], "→ 图版", len(a["plate_files"]), "图组", a["group_count"])
    for g in a["groups"]:
        for it in g["items"]:
            if it["type"] in ("教学设计图", "课件截图"):
                print("  ", it["id"], it["role"], it["type"], it["description"], it["clean"])
```

字段：`id / title / kind / figure_count / group_count / extra_count / type_mix / plate_files[] / plate_png / plate_pdf / groups[]`；
`groups[]` 内：`no / png / w / h / files[] / items[]`；`items[]` 内：`id / type / role / description / orig / clean`。
