# 插图使用规范 · AGENT 必读

> 本目录的图**已按论文版心标准化**。请严格按本规范使用，**不要做任何"智能优化"**。

---

## 0. 一句话

**每张 PNG 就是一张可直接插入论文的成品图**：宽度已等于论文双栏版心 17 cm，高度不超过一页 20 cm。直接插入即可，**不需要也无法再"更好地排版"**。

---

## 1. 硬约束（违反即排版事故）

| 禁令 | 原因 |
|---|---|
| ❌ **禁止缩放、拉伸**（非等比） | 宽度已等于版心；非等比会让文字与图像变形 |
| ❌ **禁止把多张 PNG 拼接成一张** | 每张都是一页；拼接必然产生超长图 |
| ❌ **禁止把同一篇的全部页一次性插入** | 应按正文需要挑 1–2 张 |
| ❌ **禁止裁切** | 内容按版心排版，裁切会切掉教学环节 |
| ❌ **禁止在图上叠加文字、水印、边框、编号** | 图上已无多余文字；叠加会破坏规范性 |
| ❌ **禁止把"设计页"塞进单栏** | 设计页含 8.8pt 正文，缩到单栏宽（≈50%）后字仅约 4.4pt，不可读 |
| ✅ **允许**：整体等比缩放到版心宽 | 仅限「图像组」（纯图像、无文字），且不低于原宽 50% |

---

## 2. 尺寸规范

| 项 | 值 |
|---|---|
| 画布 | **2008 px × ≤2363 px** |
| 物理尺寸 | **170 mm × ≤200 mm** |
| 分辨率 | **300 dpi**（位图像素与物理尺寸已对应，插入时按原尺寸） |
| 单页原则 | 一张 PNG = 一张图，**不存在超长图** |

实测高度只有 8 档：2363（整页）/ 1582 / 1507–1511 / 1442 / 1388 px。

**命名三段**：`F<编号>_<篇名简称>_<类型>_<序号>.png`

| 片段 | 含义 |
|---|---|
| `F01`–`F20` | 材料编号。**F01–F10 = 教案型**，**F11–F20 = 活动纪要型** |
| `设计` | ① 设计页：教学设计要素 + 教学流程（教案型）／活动概要 + 环节纪要（纪要型）。**含文字** |
| `图像` | ② 图像组：一主图 + 小图，**纯图像、零文字** |
| `_01` `_02` … | 同类内的序号；设计页多页时按阅读顺序排列 |

## 4. 两类图的分工与插入位置

### ① 设计页 `_设计_NN.png`（含文字）

- **内容**：课题 → 教学设计（教材分析／教学目标／教学重难点／教学准备）→ 教学流程（按课时的环节，关键环节右侧锚定课件截图）；纪要型为 活动概要 → 环节纪要
- **信息密度高**，是"这节课怎么教"的完整呈现
- **插入位置建议**：论文的**课例分析章节**（整幅/跨栏）或**附录**
- 多页时按 `_01 → _02` 顺序，可分别插入并标注"图 N(a)、图 N(b)"

### ② 图像组 `_图像NN.png`（纯图像）

- **内容**：一组同质图像（课堂实拍／课件页／板书），一张主图 + 若干小图
- **零文字**，可直接作为**证据图**
- **插入位置建议**：正文中论证性段落旁，可等比缩至单栏宽

## 6. 图注规范

图上**不含**图注（已刻意移除）。图注由论文正文按需撰写：

```
图 3  六上第7课《开国大典》教学设计与教学流程
图 4  开国大典课堂实况（左：教师示范；右：学生活动）
```

- 编号按论文自身图序连续，**不要照搬文件名里的 F 编号**
- 若需标明页面来源，写"第 N 页（共 M 页）"，不要写文件路径

## 7. 程序化调用

```python
import json, os

BASE = os.path.expanduser("~/桌面/小学/tese/论文插图")
idx  = json.load(open(os.path.join(BASE, "插图索引.json"), encoding="utf-8"))

# 尺寸规范与禁令（务必先读）
print(idx["spec"])    # {'width_px':2008, 'height_max_px':2363, 'dpi':300, 'width_mm':170, ...}
print(idx["rules"])   # 5 条硬约束

# 按篇取图
a = next(x for x in idx["articles"] if x["id"] == "F08")
for p in a["pages"]:
    print(p["role"], p["no"], p["mm"], p["png"])   # mm = [宽mm, 高mm]

# 只要"图像组"（纯图像，适合正文）
for a in idx["articles"]:
    for p in a["pages"]:
        if p["role"] == "图像组":
            print(p["png"])
```

**字段**

| 层级 | 字段 |
|---|---|
| 顶层 | `spec` `rules` `total_articles` `total_pages` `articles[]` |
| 篇 | `id` `title` `kind` `dir` `pdf` `page_count` `pages[]` |
| 页 | `no` `role`(图版页/图像组) `png` `w` `h` `mm` |

## 8. 溯源与素材

需要**单张原图**（而非拼好的成品图）时：

| 路径 | 说明 |
|---|---|
| `~/桌面/公众号文章库/<篇名>/images/` | 该篇全部内容图（已剔除装饰图） |
| `~/桌面/公众号文章库/_clean/<篇名>/images/` | 已去水印、白底归一化版本（推荐） |
| `~/桌面/公众号文章库/<篇名>/文章.md` | 该篇正文与元信息 |
| `~/桌面/公众号文章库/_装饰图（已剔除）/` | 被剔除的装饰图（页眉横幅/二维码/图标/色块） |

## 9. 反例（不要这样做）

| 做法 | 后果 |
|---|---|
| 把 `_设计_01` 和 `_设计_02` 上下拼成一张 | 变成 17×40 cm 超长图，无法放入版面 |
| 把 `_设计_NN` 塞进单栏并缩到 8 cm 宽 | 正文缩到约 4pt，不可读 |
| 给图像组加标题条、边框、说明文字 | 破坏"纯图像"定位，且与论文图注重复 |
| 用 `_设计` 页替代图像组放进"课堂实况"段落 | 图文不符 |
| 把 20 篇的图全部插入 | 篇幅失控；应精选与论点直接相关的 |

## 10. 设计约束回顾（为什么是现在这样）

| 设计决策 | 原因 |
|---|---|
| 宽度固定 17 cm | 等于论文双栏整幅版心，插入即用 |
| 高度 ≤20 cm | 不超过一页，**从机制上杜绝超长图** |
| 一页一张 PNG | agent 直接插入不会出错 |
| 图上无页脚说明/来源署名/单位地址 | 按要求移除；图注由正文撰写 |
| 图像组零文字 | 避免与正文图注重复、便于缩放到单栏 |
| 只保留有真实场景或教学内容的图 | 已剔除 138 张装饰图（校徽、色块、二维码、图标等） |
