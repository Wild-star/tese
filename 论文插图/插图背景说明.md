# 插图背景说明

> 面向 agent 的结构化说明。每篇材料拆分为 **1 张图版 + 若干图像组**，均给出文件路径、构成与建议图注。
> 图像文件本身不叠加任何标注；机器可读版本见同目录 `插图索引.json`。

**共 20 张图版 + 14 个图像组 · 涵盖 130 张图像**

## 0. 使用须知

| 项 | 说明 |
|---|---|
| 拆分规则 | 每篇 = **1 张图版**（教学设计／活动纪要）+ **若干图像组**（每组 ≤4 张，采用「一主图 + 小图」自适应排版） |
| 文件命名 | `<F编号>_<篇名简称>_图版.png/.pdf`、`<F编号>_<篇名简称>_图组NN.png` |
| 尺寸 | 图版宽 2309px；图像组宽 1800px；均为 @300dpi |
| 排版取向 | 单张成品图内**图像数量受控**，避免版块过大，便于按单栏/双栏插图放置 |
| 图像处理 | 已去水印、白底归一化；**未做**艺术化/滤镜/AI 重绘 |
| 已排除 | 无真实场景的纯文字宣传图（校徽、校训/校风/教风/学风板块、二维码尾图、页眉横幅、分隔条、图标等） |
| 已弱化 | 举办单位、承办单位与地址信息（图版中不出现） |
| 像素限制 | 个别课件截图原始分辨率偏低（如 484×172），仅适合小尺寸插图 |
