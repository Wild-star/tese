## 二、插图怎么用

### 三种文件选哪个

| 需求 | 用哪个 |
|---|---|
| 论文里放"这一节课怎么教的"整体呈现 | **`_图版.png`**（教学设计要素 + 教学流程；或活动概要 + 环节纪要） |
| 论文里只放图像证据 | **`_图组NN.png`**（一主图 + 小图，同质图像聚合） |
| 需要矢量 / 可编辑 / 文字可检索 | **`_图版.pdf`**（文本层可提取，非扫描件） |

### 尺寸（便于排版定版心）

| 类型 | 宽度 | 高度范围 | 中位 |
|---|---|---|---|
| 图版 | 2309 px | 9.3 – 31.2 cm | 17.4 cm |
| 图组 | 1800 px | 11.4 – 13.4 cm | 12.3 cm |

均按 300 dpi 输出，直接插入 Word/WPS 即可，无需再缩放。

### 命名规则

```
F<编号>_<篇名简称>_图版.png        主图（若该篇含 2 课时，拆为 _图版1 / _图版2）
F<编号>_<篇名简称>_图组NN.png      图像组（每篇 0–3 组，组内 4–9 张）
```

`F01–F10` 为教案型，`F11–F20` 为活动纪要型。

## 四、程序化调用（给 agent）

```python
import json, os

D = os.path.expanduser("~/桌面/论文插图")
idx = json.load(open(os.path.join(D, "插图索引.json"), encoding="utf-8"))

# 1) 列出某篇的全部成品图
a = next(x for x in idx["figures"] if x["id"] == "F08")
print(a["title"], a["kind"])
print("图版：", a["plate_files"])
print("图组：", [g["png"] for g in a["groups"]])

# 2) 按图像类型筛选（只取教学设计图/课件截图）
for a in idx["figures"]:
    for f in a["figures"]:
        if f["type"] in ("教学设计图", "课件截图"):
            print(f["id"], f["type"], f["description"], f["clean"])

# 3) 找某张图属于哪个教学环节
for a in idx["figures"]:
    for f in a["figures"]:
        if f["stage"]:
            print(a["id"], f["id"], f["period"], f["stage"])
```

**字段说明**

| 层级 | 字段 |
|---|---|
| 顶层 | `total_articles` / `total_images` / `total_groups` / `figures[]` |
| 篇 | `id` `title` `kind` `figure_count` `group_count` `extra_count` `type_mix` `plate_files[]` `plate_png` `plate_pdf` `groups[]` |
| 图组 | `no` `png` `w` `h` `files[]` `items[]` |
| 单图 | `id`(图N) `type` `role` `description` `orig`(原图) `clean`(净化图) |

## 五、常见操作

| 想做 | 怎么做 |
|---|---|
| 查某张插图的内容 | `插图背景说明.md` 搜 `F编号`，看"逐图清单"表 |
| 换掉某张插图里的某张原图 | 替换 `_clean/<篇名>/images/` 中的对应文件，然后重跑打包（见下） |
| 只想拿图像、不要文字 | 用 `_图组NN.png`；或从 `_clean/<篇名>/images/` 取单张 |
| 恢复被剔除的装饰图 | 在 `_装饰图（已剔除）/` 里按篇名找 |
| 补抓新文章 | `wx-fetch -f ~/桌面/公众号文章库/链接清单.txt --gif smart` |

## 六、注意事项

- **图像处理**：已去水印 + 白底归一化；**未做**艺术化/滤镜/AI 重绘，内容未被改动
- **已排除**：无真实场景的纯文字宣传图（校徽、校训/校风/教风/学风板块）、页眉横幅、二维码尾页、分隔条、图标、矢量色块
- **已弱化**：举办单位、承办单位与地址不出现在图版中
- **像素限制**：个别课件截图原始分辨率偏低（如 484×172），只适合小尺寸插图
- **不要直接删 `公众号文章库/`**：它是长期资产；`_装饰图（已剔除）/` 里的是按篇名分目录存放的装饰图，可随时找回
