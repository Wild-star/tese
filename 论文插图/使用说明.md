# 论文插图 · 使用说明

> 路径：`~/桌面/小学/tese/论文插图/`
> **agent 使用前请先读 `插图使用规范（AGENT必读）.md`**

---

## 一、尺寸规范

| 项 | 值 |
|---|---|
| 画布 | 2008 px × ≤2363 px |
| 物理尺寸 | **170 mm × ≤200 mm**（论文双栏整幅版心） |
| 分辨率 | 300 dpi |
| 原则 | **一张 PNG = 一张图**，无超长图 |

## 二、目录

```
论文插图/
├── 插图使用规范（AGENT必读）.md   ← 给 agent 的硬约束与选图规则
├── 使用说明.md                    本文件
├── 插图索引.json                  程序化索引（含 spec / rules / 全部路径）
└── F01_…/  ~  F20_…/              20 篇材料，共 43 张图
    ├── F0N_…_设计_01.png          设计页（含文字）
    ├── F0N_…_设计_02.png          设计页续页
    ├── F0N_…_设计.pdf             合并 PDF
    └── F0N_…_图像01.png           图像组（纯图像）
```

## 三、两类图怎么用

| 图 | 内容 | 插入位置 | 可否缩放 |
|---|---|---|---|
| `_设计_NN.png` | 教学设计要素 + 教学流程（或活动概要 + 环节纪要），**含文字** | 课例分析章节整幅/跨栏，或附录 | ❌ 只能按原尺寸 |
| `_图像NN.png` | 一主图 + 小图，**纯图像零文字** | 正文论证段落旁 | ✅ 可等比缩到单栏宽（不低于原宽 50%） |
| `_设计.pdf` | 同上，文本层可检索 | 需要矢量/检索时 | — |

## 五、图上有什么字

- **无**页脚说明、**无**来源署名、**无**举办单位与地址
- 设计页保留结构性文字：课题、栏目名（教学设计／教学流程）、教学环节名 — 这些是内容本身
- 图像组**零文字**

## 六、图注

按论文自身图序编号，**不要照搬文件名里的 F 编号**。例：

```
图 3  六上第7课《开国大典》教学设计与教学流程
图 4  开国大典课堂实况
```
